# ربات‌ساز موسیقی تلگرام (نسخه پایه قابل اجرا)

این پروژه یک ربات‌ساز مرکزی پایتون است که امکان ثبت و راه‌اندازی چند ربات موسیقی مستقل را فراهم می‌کند. ربات‌های فرزند از موتور اجرایی مشترک استفاده می‌کنند و هر کدام توکن و هویت تلگرام خود را دارند.

## امکانات پیاده‌سازی‌شده
- منوی اینلاین فارسی ربات‌ساز
- SQLite پایدار و ثبت کاربران، ربات‌ها، جست‌وجوها و تراکنش‌ها
- قیمت پیش‌فرض ساخت: **۵۰۰ الماس**
- اعتبارسنجی توکن با Telegram Bot API
- کسر تراکنشی الماس و بازگشت هزینه در صورت شکست اعتبارسنجی/راه‌اندازی
- راه‌اندازی چند ربات فرزند در یک پردازش
- جست‌وجوی واقعی آهنگ با Apple iTunes Search API و نمایش حداکثر ۱۰ نتیجه
- انتخاب نتیجه و ارائه لینک رسمی صفحه آهنگ/پیش‌نمایش، در صورت موجود بودن
- پنل مرکزی پایه برای آمار، قیمت، تراکنش‌ها، فهرست ربات‌ها و شارژ دستی
- دستورات مدیر: `/setprice 500` و `/adddiamonds USER_ID AMOUNT دلیل`
- فایل دیتابیس با WAL

## محدودیت‌های صریح نسخه پایه
- دریافت فایل کامل آهنگ از منابع غیرمجاز پیاده‌سازی نشده است. این پروژه لینک رسمی صفحه آهنگ و پیش‌نمایش را ارائه می‌کند؛ موجود بودن پیش‌نمایش به کاتالوگ بستگی دارد.
- پرداخت خودکار، درگاه بانکی، بسته‌های قابل خرید، پیام همگانی، مدیریت کامل کاربران و گزارش‌های حرفه‌ای هنوز پیاده‌سازی نشده‌اند. شارژ الماس فقط توسط مدیر و پس از تأیید واقعی پرداخت انجام شود.
- پنل اختصاصی هر ربات در این نسخه پایه است؛ آمار تفصیلی، مدیریت منابع، ویرایش کامل دکمه‌ها و متن‌ها در نسخه فعلی وجود ندارد.
- توکن ربات‌ها در SQLite به شکل متن ذخیره می‌شود؛ فایل دیتابیس را محرمانه نگه دارید و دسترسی دستگاه/سرور را محدود کنید. برای استقرار عمومی، رمزنگاری توکن‌ها و مدیریت اسرار باید اضافه شود.
- ربات‌ها در همین پردازش اجرا می‌شوند. اگر Termux بسته شود یا اندروید پردازش را متوقف کند، ربات‌ها هم از دسترس خارج می‌شوند.

## نصب در Termux
```bash
pkg update
pkg install python -y
mkdir -p ~/music_bot_builder
cd ~/music_bot_builder
```
فایل‌های ZIP را استخراج کنید، سپس:
```bash
python -m pip install -r requirements.txt
cp .env.example .env
nano .env
```
مقدار `BUILDER_BOT_TOKEN` را با توکن ربات مرکزی عوض کنید. `ADMIN_IDS` را با شناسه عددی تلگرام خود تنظیم کنید. برای دریافت شناسه می‌توانید از یک ربات معتبر نمایش شناسه استفاده کنید؛ شناسه را از منبع مطمئن بررسی کنید.

اجرا:
```bash
python main.py
```

## شارژ اولیه برای تست
پس از اجرای ربات، از حساب مدیر در چت خصوصی ربات دستور زیر را بفرستید:
```text
/adddiamonds USER_ID 1000 شارژ آزمایشی
```
`USER_ID` شناسه عددی کاربر است. بعد از شارژ، کاربر می‌تواند ربات فرزند بسازد. در نسخه پایه بسته خرید واقعی وجود ندارد؛ برای تست از الماس آزمایشی استفاده کنید.

## ساخت ربات فرزند
1. در تلگرام به `@BotFather` بروید و `/newbot` را اجرا کنید.
2. توکن ربات فرزند را کپی کنید.
3. در ربات‌ساز روی «ساخت ربات موسیقی» بزنید و توکن را ارسال کنید.
4. ربات‌ساز توکن را با Telegram API اعتبارسنجی و ربات را اجرا می‌کند.

## امنیت
- توکن‌ها را در گروه‌ها یا چت عمومی نفرستید.
- فایل `.env` و `music_builder.sqlite3` را منتشر نکنید.
- اگر توکن افشا شد، از BotFather آن را لغو و توکن جدید بگیرید.
- ربات‌ساز مرکزی را فقط با مدیران مورد اعتماد اداره کنید.
